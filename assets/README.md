# starter.html

Copy `starter.html` to start every new page, then replace the hero text and everything inside `<main>` with your own content. Keep the `<head>`, the whole `<style>` block, the hidden SVG with `#k2wob` and `#k2ink`, and the script at the end exactly as they are: they hold the 13 grounds, the ink buttons with `localStorage`, the edge-to-edge spread for `.sp` lines, and the tooltips. The starter shows one working example of every component, so copy markup from it rather than writing new CSS.
