# beautify-artifact

An agent skill for designing single-file HTML pages (plans, studies, scripts, reports) in one house style: a dense label sheet. One ink on one flat ground, thin hand-drawn lines, small mono labels, a few large plain values, with barcodes, rulers and dimension lines as decoration.

## What is here

| Path | What it is |
|---|---|
| `SKILL.md` | The instructions: colours, type, components, content rules and build steps. |
| `assets/starter.html` | A complete page holding every component. Copy it to start a new page. |
| `assets/README.md` | How to use the starter. |
| `CHECKLIST.md` | The checks to run before showing a page. |

## Install

Copy this folder into your agent's skills directory, for example `~/.claude/skills/beautify-artifact/` for Claude Code.
